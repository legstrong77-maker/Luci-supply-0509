# 圖片放置位置 ／ Photo Placement Guide

把照片直接覆蓋以下檔名（保留 `.jpg` 副檔名），重新整理頁面即可。
若暫時沒有檔案，CSS 會自動使用漸層背景，畫面仍能正常呈現。

## 必要檔案

| 檔名 | 用途 | 建議比例／尺寸 |
|---|---|---|
| `hero.jpg` | 首頁巨幅主視覺（建議用紀念石碑那張） | 直式或橫式皆可，至少 1920×1080，可大可小 |
| `story-1.jpg` | 「關於我們」左大圖（建議竹林直式） | 直式 4:5，1200×1500 |
| `story-2.jpg` | 「關於我們」右下小圖（建議步道指標） | 直式 4:5，1000×1250 |
| `gallery-1.jpg` | 影像紀錄（紀念碑） | 橫式 |
| `gallery-2.jpg` | 影像紀錄（孟宗竹海） | 橫式 |
| `gallery-3.jpg` | 影像紀錄（指示牌） | 直式 |
| `gallery-4.jpg` | 影像紀錄（合影） | 直式 |
| `gallery-5.jpg` | 影像紀錄（隊伍上山） | 直式 |
| `gallery-6.jpg` | 影像紀錄（橫幅大圖，建議竹林全景） | 橫式 16:9 |
| `join-bg.jpg` | 「加入我們」整段背景（建議竹林大景） | 橫式 1920×1080 |

## 推薦對應（依您本次提供的照片）

1. 紀念石碑「嘉南雲峰步道」  → `hero.jpg`、`gallery-1.jpg`

3. 木製指示牌「石壁山 / 嘉南雲峰」 → `story-2.jpg`、`gallery-3.jpg`
4. 隊伍合照（豎大拇指）         → `gallery-4.jpg`
5. 隊伍上山背影                 → `gallery-5.jpg`
6. 竹林橫幅                     → `gallery-6.jpg`
